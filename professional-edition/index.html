Trauma-Informed Use Guidance When used in professional settings, adherence to ethical and trauma-informed practices is paramount:
  • Obtain consent
  • Allow the client to pause or pass
  • Use only one card if needed
  • Offer emotional containment and aftercare
  • Never pressure for disclosure
  • Refer if deep trauma is triggered
  • Life review sessions
  • Legacy and memory work
  • Grief processing
  • Inner child healing
The facilitator’s role is to hold space, not diagnose, interrogate or advise.

Suggested Session Formats

One-to-one session

  • Gentle sharing
  • Closing ritual
  • Optional journalling

Group session

  • Intention setting
  • Passing of decks
  • Each person draws one card
  • Optional sharing circle
  • Closing blessing
