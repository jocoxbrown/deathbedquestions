# Death Bed Questions website

This is the Jekyll source for deathbedquestions.com.

## Publish a writing

Copy `_posts/POST-TEMPLATE.md`, rename it using `YYYY-MM-DD-title.md`, update the title, date and description (add an optional `image:` path such as `/assets/images/my-photo.jpg` to show a picture on the Writings page), then write below the second `---` line. Delete `published: false` when the post is ready to appear.
